# How to cite this snapshot

The matrix changes when the pages behind it change, so cite a commit, not the branch.
This file is the anchor.

**Snapshot 2026-11-17 · 106 domains · 101 readable**

```
Zeng, J. (2026). AI trust centers: topic coverage across 106 published pages
(snapshot 2026-11-17) [Data set]. Exhibitrail.
https://github.com/contentforge-press/exhibitrail-assessments/blob/059f1e9b0f0c31efe86e7acb96398b5b40ba7a5c/data/trust-center-coverage.csv
```

Rules we hold ourselves to when this number is cited:

1. **Cite the commit.** The branch will move. A number without a commit is a rumour.
2. **Say "mentions", not "implements".** The column records a string on a page.
3. **Never quote the 5% and 7% without the denominator.** Five of 101 pages, not five percent
   of the industry.
4. **If you recompute it, publish your own CSV.** Two datasets that disagree are more useful
   than one that cannot be checked.

## What this is not

Not a ranking. Not a judgement about any company's security posture. A page can be silent on
a topic and still handle it well in code; a page can discuss a topic and fail the corresponding
test. The only claim here is what a buyer would *see* if they opened the trust center.
