What a review is

Twenty-four tests in six classes — instruction boundary, action authority, memory isolation, retention, sub-processor chain, version lock. Five working days from signed scope to a verdict. Written scope with eight rules of engagement, signed before anything is touched.

Nothing outside the written scope is tested. Public demos are never exercised. A finding is published only with the reasoning that separates it from a scanner artifact.

The two questions that cut through most of it:

What can your agent change without a human approving it — and where is that list?

If a page your agent reads tells it to do something, what makes that data instead of a command?

A vendor who answers these precisely has done work no certificate covers. A vendor who answers “guardrails” has told you where the gap is.
